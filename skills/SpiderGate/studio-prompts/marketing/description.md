# SpiderGate Studio — saved prompts

The agent-native creative studio: every image/video/audio model, one shared
workspace, humans and agents side by side.

A saved prompt bundles a system prompt, a model, its settings and any reference
media under one name inside a Studio project. A human loads it from the composer
gallery in one click; an agent references it as `prompt:<public_id>` and the
server expands it in place, with request values always winning.

This skill manages those bundles and the projects that hold them — create,
search, read, update, delete — so an agent can build its own reusable prompt
library instead of pasting the same text every session.
